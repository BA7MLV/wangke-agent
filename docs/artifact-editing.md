# 图表与 HTML 的独立修改

已完成回答中的 diagram、SVG、Mermaid、HTML 围栏以及 HTML widget，可点击「修改此图 / 修改此 HTML」。

1. 在图形下方直接输入修改要求，不弹出遮挡页面的模态框。题意与隐私范围说明按需展开，不自动携带完整课程或会话。
2. 「生成局部修改」只请求精确匹配的 search/replace JSON 补丁。生成可收起、停止；其他图形、阅读和聊天不受其锁定。
3. 收起、虚拟列表卸载和切换会话不取消请求；目标被删除或改动时自动停止。进度、要求和待应用结果暂存内存，回到原图可继续；刷新页面不保留这些草稿，也不会自动重新请求。
4. 匹配或校验失败时就近报错并保留原内容。可在「更多选项」显式选择「仅重生成此块」，不自动追加付费请求。
5. 默认直接预览修改效果，源码对比按需展开；点击「应用修改」才原位保存。不同图形可分别生成和应用，事务只检查目标图，保留其他修改。
6. 当前消息挂载期间保留最近 10 次修改，可分别撤销对应图形的最近修改。刷新或虚拟列表卸载后撤销记录不保留，已应用内容仍持久保存。

## 成本与安全

- 独立调用当前设置的 chat 模型，不调用工具，也不发送会话历史、其他图表或内联运行库。
- 输入仍包含完整目标块；这是**降低输出与会话输入成本**，不保证只发送一个图元。大块后续可升级稳定 ID + 按需读取协议。
- 所有补丁都基于同一份原始源码定位，歧义、重叠、无变化和空结果均拒绝。重复的相同围栏暂不支持修改，避免误改。
- IndexedDB 事务内检查目标源码及唯一位置；目标被删除、改动或回答挂起时拒绝保存。其他图形或正文发生变化时不会误覆盖，也不要求无关图形重做请求。
- diagram 校验 schema 并试渲染；SVG 走原净化器；Mermaid 试渲染。HTML 只做基础形态检查，不能保证交互正确。
- HTML 静态预览仍由 DOMPurify 净化，widget 仍由原有不透明源 iframe + CSP 执行。修改功能不会放宽权限。
- 重新渲染不消耗模型 tokens；HTML widget 更新会重挂 iframe，内部交互状态会重置。
- 补丁结果不是视觉正确性的证明。支持应用后撤销，不宣称已经自动检查了图像语义。
- 修改预览复用原渲染边界：静态 HTML 仍净化，交互 HTML 仍运行于同样的隔离 iframe；不绑定消息快照、不开放付费追问或弹出窗口。预览交互不会污染原图状态。
