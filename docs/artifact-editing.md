# 图表与 HTML 的独立修改

已完成回答中的 diagram、SVG、Mermaid、HTML 围栏以及 HTML widget，可点击「修改此图 / 修改此 HTML」。

1. 输入修改要求；必要题意可手动补充，不自动携带完整课程或会话。
2. 「生成局部修改」只请求精确匹配的 search/replace JSON 补丁。
3. 匹配或校验失败时保留原内容，可显式选择「仅重生成此块」，不自动追加付费请求。
4. 检查修改前后源码，点击「应用修改」后原位保存；其他文字、图表、思考、工具记录不变。
5. 当前消息挂载期间保留最近 10 次修改，可依次撤销。刷新或虚拟列表卸载后撤销记录不保留，已应用内容仍持久保存。

## 成本与安全

- 独立调用当前设置的 chat 模型，不调用工具，也不发送会话历史、其他图表或内联运行库。
- 输入仍包含完整目标块；这是**降低输出与会话输入成本**，不保证只发送一个图元。大块后续可升级稳定 ID + 按需读取协议。
- 所有补丁都基于同一份原始源码定位，歧义、重叠、无变化和空结果均拒绝。重复的相同围栏暂不支持修改，避免误改。
- IndexedDB 事务内检查原内容；回答被删除、改动或挂起时拒绝保存。保存只更新 content 或 widget 字段。
- diagram 校验 schema 并试渲染；SVG 走原净化器；Mermaid 试渲染。HTML 只做基础形态检查，不能保证交互正确。
- HTML 静态预览仍由 DOMPurify 净化，widget 仍由原有不透明源 iframe + CSP 执行。修改功能不会放宽权限。
- 重新渲染不消耗模型 tokens；HTML widget 更新会重挂 iframe，内部交互状态会重置。
- 补丁结果不是视觉正确性的证明。支持应用后撤销，不宣称已经自动检查了图像语义。
