# TypeSafe Jev 适配

Jev 是决策模型，不生成文字，也不直接识别图片、音频或视频。本项目使用独立的
`POST /v1/systemone` 客户端，不将它混进文本 / 视觉 / 语音三个生成模型槽位。

## 配置

在「设置 → 模型 → Jev 决策模型」填写：

- API 地址：默认 `https://api.typesafe.ai/v1`，浏览器直连要求服务端允许 CORS。
- API Key：仅保存在本机 localStorage。
- 模型 ID：默认固定 `jev-1.13.0`，避免别名升级静默改变阈值效果；可自行修改。

两个功能开关均默认关闭，可以分别启用。除了手动「测试 Jev 连接」，打开设置不会
调用决策接口。连接配置、凭据与启用授权不参与云同步或迁移包导出。

**出网范围**：技能路由发送课程名、字幕样本与技能元数据；上下文压缩发送当前问题、
最近两轮的文本，以及本批待评估的旧轮次。不会发送图片、视频、音频或消息的非文本元数据。
这些内容会交给配置的第三方服务处理，不是本地推理。

## 讲义技能路由

`src/skills/jevRoute.ts` 对每项技能提出一个 Noul 问题，可同时启用多项技能。
概率 ≥ 0.8 时选用、≤ 0.2 时排除；任何判断落在中间区间时整次退回原 LLM 路由。
未配置、超时、限流、输入过长或响应异常也退回原路由；用户设置的 `pin` / `drop`
始终最后应用，原有「LLM 也失败则启用全部技能」的兜底不变。

## 长对话上下文压缩（实验性）

`src/harness/jevContext.ts` 执行**抽取式筛选**，不是生成摘要；
`src/store/contextCompression.ts` 管理每条会话独立的压缩计划：

1. **自动**：上下文达到输入预算上限时触发。输入预算为窗口减去 4096 tokens 的回答预留；
   发送前还会用实际系统提示、当前问题与图片开销再次校验。未达到上限不自动调用。
   **手动**：点击输入框的上下文用量环立即压缩，不受长度门槛限制。手机端同样保留入口。
2. 一轮用户提问与随后的所有 assistant 消息作为一个整体，不拆散选择。
3. 最近两轮不参与语义删除；旧轮次中的挂起检查点与中断回答也不参与判断。
4. 只有「整轮可安全省略」概率 ≥ 0.95 才省略；要求保留仍适用的偏好、约束、
   决策、未完成任务和当前请求需要的事实。重复信息必须已出现在受保护的最近上下文中，
   不能依赖另一个同样可能被删的旧轮次。
5. 最多评估最近 32 个旧轮次、最多 4 个并行批次。每批完整 JSON 不超过 30,000 UTF-8
   字节；单个过大的轮次跳过评估，绝不截断后判断。
6. 按时间顺序拼回选中的原文，最后按窗口预算裁剪整轮。预算仍可能淘汰历史，
   「未参与语义删除」不代表可以突破上下文窗口。

覆盖课程助手与播放器 / 阅读器问答的**普通发送**。系统提示、当前问题和当前回合的
工具调用链不在筛选范围内；挂起续跑与中断续写保持原逻辑。没有可删除项或请求失败时，
仍使用原有从最近消息向前截取的策略。用户按停止会取消决策请求，不继续调用 LLM。

压缩后的发送计划在当前页面生命周期内按会话缓存，后续请求复用，环上的估算用量也按
保留文本计算。切换会话不会串用；行内容编辑后不再沿用该行的旧筛选结果。刷新页面、
关闭压缩功能或清空 Key 后恢复完整历史的原有预算裁剪逻辑，不持久化额外副本。

图标使用 transitions.dev 的 **Icon swap / Success check**：压缩中旋转、完成时显示勾选，
环形用量平滑变化，状态通过读屏提示。`prefers-reduced-motion` 关闭旋转与过渡。
失败或没有可安全省略项时明确反馈，不伪报成功；同一份满载历史不会因失败反复自动请求，
仍可手动重试。

不删除、修改或另存数据库中的历史。当前不压缩工具结果正文，也不生成持久化会话摘要。

以上阈值是保守的初始策略，并未用真实中文课程完成质量校准。概率高不保证语义正确，
上线前应比较真实对话的保留率、回答质量、总延迟与成本；更换模型版本后重新评估。

## 验证

```bash
node scripts/test-jev.mjs          # 客户端、失败回退、裁剪不变量、技能覆盖、凭据隔离
node scripts/test-sync-units.mjs
npm run build

# 先启动 dev server，再运行独立浏览器上下文的假网关测试（不使用真实凭据）
BASE_URL=http://localhost:5173 node scripts/e2e-jev.mjs
```
