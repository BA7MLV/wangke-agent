# 阅读材料批注

## 使用

- 默认「智能批注」：主动触控笔落笔即书写，手指拖动阅读，鼠标拖选文字。落笔期间屏蔽触摸滚动，已被识别为掌触的接触必须离屏后才能重新参与手势。
- 「阅读 / 选字」保留浏览器原生滚动和选字。
- 「文字荧光笔」：手指、笔或鼠标拖过文字，按字和行生成高亮，抬手后回到智能批注。支持 PDF 文字层、Word、Markdown 和 HTML 分段视图。单次选取限于当前页面/渲染段落。
- 扫描件没有文字层时使用「自由荧光笔」，同样一笔后恢复智能批注。
- 「高亮摘录」可查看原文及来源、引用提问、删除；删除和绘制都可撤销/重做。
- 被设备识别为普通触摸的电容笔使用「画笔 → 启用手指绘制」。HTML 原样视图仍保留沙箱，选择批注工具后切到分段视图。

## 存储与显示

文字高亮在 `materialInk` 中独立保存，不修改导入文件或正文 DOM：

- `anchor` 采用 TextPositionSelector + TextQuoteSelector 的定位思路：字符区间、原文、前后文、页/段及材料格式。
- 缩放、重排、字体加载和 PDF 文本层重建后，按锚点和 DOM Range 重新计算 SVG 矩形。
- 同一句出现多次且无法唯一定位时不猜位置。Markdown/HTML 正文修改后仍沿用内容签名隔离，旧摘录可查看，但不会覆盖到新内容上。
- `rects` 保存规范化快照供 PDF 问答裁图使用。兼容原有笔迹记录，无需数据库迁移。
- 更新高亮预览按动画帧合并；一次拖选缓存文字命中几何，布局变化后重新测量。

## 问答

- 引用提问发送带来源的 `<mark>高亮原文</mark>`；原文中的标签和 `&` 会转义。
- `grep` / `read` 材料正文时附带命中页/段的相关高亮。
- `read /courses/current/highlights` 或 `/courses/{id}/highlights` 可分页读取高亮摘录，每页最多 5 条，每条最多 3000 字符并明确标记截断。
- 高亮是用户关注点和摘录快照，不提升其事实可信度；模型须区分用户标注与原文，材料编辑后结合当前正文核对。

## 验证

开发服务器运行时：

```sh
node scripts/e2e-material-ink.mjs
node scripts/e2e-material-highlights.mjs
node scripts/test-resource-tools.mjs
npm run build
```

浏览器测试使用 CDP 触摸/笔输入，覆盖输入仲裁、默认落笔、跨行反向选择、重排字形覆盖、取消、橡皮、持久化、四种格式与模拟模型的实际请求/工具结果。物理设备的系统级掌触拒绝仍需实机验收。
