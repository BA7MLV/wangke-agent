# MCP 接入

入口：**设置 → 技能与 MCP → MCP**。原有 `#/settings/skills` 链接继续有效。

## 支持范围

- **Streamable HTTP**、旧 **HTTP + SSE** 和后端 **stdio**；官方 TypeScript SDK 固定版本 `1.32.2`，运行于 Node 后端。
- 无认证、Bearer Token、自定义请求头（JSON）及 OAuth 授权码 + PKCE。凭据、OAuth 状态和 stdio 环境变量只写入服务器加密存储，编辑时留空保留，填写替换，也可显式清除。
- 服务器与工具启停、连接测试、分页工具发现、参数查看、文本／结构化结果、耗时和失败状态。
- JSON 配置预览／批量导入、Resources／资源模板／Prompts、超预算工具目录按需发现，以及技能 MCP 依赖提示。
- 资料库助手、视频课程问答、阅读问答及 Bot。普通后台生成流水线不会自动获得 MCP。
- 同一个账户的设备共用服务器配置；关闭浏览器后，已提交后台任务仍可执行 MCP。

图片和二进制资源等未适配内容会明确标记为未展示；资源链接和文本资源可传回模型。Prompts 作为数据返回，不自动替换系统提示词。

## 添加连接

1. 填写名称，选择 Streamable HTTP 或 HTTP + SSE，填写对应 MCP URL，例如 `https://example.com/mcp` 或旧服务的 `/sse` 入口。
2. 选择认证方式。自定义请求头示例：`{"X-API-Key":"your-key"}`。认证信息放在此处，不放进 URL 查询参数。
3. 设置超时（1–120 秒，默认 30 秒），保存并点击「测试连接」。测试只初始化协议并发现工具，不执行业务工具。
4. 「查看工具」里可检查参数或关闭不需要的工具。外部服务新增工具后重新测试连接以刷新目录。

地址必须是 **后端服务器能够访问的地址**。`localhost` 指后端所在的主机／容器，不是手机或访问网页的电脑；Docker 内可用服务名连接同网络内的 MCP 服务。浏览器只调用本项目 API，无需让 MCP 服务对浏览器开放 CORS。无后端模式会显示连接提示。

## OAuth

1. 公开部署设置 `MCP_PUBLIC_ORIGIN=https://learn.example.com`；未设置时使用已有 `PUBLIC_ORIGIN`。本机开发可自动使用 localhost／127.0.0.1 的后端地址。
2. 添加远程连接，认证选择 OAuth，保存后点击「开始 OAuth 授权」，再打开授权链接。
3. 服务方授权完成后回到设置，点击「刷新」「测试连接」。回调地址为 `{公开 origin}/api/v1/cloud/mcp/{服务器 id}/oauth/callback`。

支持 OAuth 元数据发现和动态客户端注册；需要手工预注册 client ID／secret 的服务暂未提供配置入口。SDK 在令牌失效时使用 refresh token 续期；无法续期时会提示重新授权。OAuth 客户端信息保留 SDK 的 issuer 绑定，授权 state 有效期十分钟且只能使用一次，PKCE verifier 与令牌均持久化加密保存。

「断开授权」立即清除本地凭据，使进行中的旧授权结果失效；有 RFC 7009 撤销端点时尝试撤销远程令牌，界面明确说明是否获远程确认。反向代理应避免记录 OAuth 回调的查询串（其中含临时授权码）；应用回调路由已关闭请求日志。

## JSON 配置导入

点击「导入 JSON」，粘贴 `mcpServers`、`mcp.servers` 或 `servers` 格式。预览阶段校验连接类型、地址、命令、凭据和数量，只显示名称与类型；确认后原子写入，任一条失败都不导入。同名服务器（含去除前后空格后重名）不会被覆盖。最多配置 30 个服务器。

```json
{
  "mcpServers": {
    "资料检索": { "type": "http", "url": "https://example.com/mcp" },
    "旧服务": { "type": "sse", "url": "https://legacy.example.com/sse" },
    "本地工具": {
      "command": "node",
      "args": ["/opt/mcp/server.mjs"],
      "cwd": "/opt/mcp",
      "env": { "API_KEY": "replace-me" },
      "disabled": true
    }
  }
}
```

支持 `type`／`transport`、`url`、`command`、`args`、`cwd`、`env`、`headers`、`enabled`／`disabled`、`timeoutMs`／`timeout`（毫秒）。未知字段会报错；`${env:...}`、`${input:...}` 等变量须事先替换。OAuth 连接导入后在编辑页选择 OAuth 并发起授权。

## stdio 进程

选择 stdio 后填写程序、JSON 参数数组、服务器绝对工作目录和环境变量 JSON。命令以 **后端服务账号** 的权限运行，使用参数数组直接启动，不经过 shell。依赖需预装在后端环境中；环境变量留空保留，`{}` 显式清空。密钥应放环境变量，程序名与参数属于可见配置。

进程首次测试／使用时启动，在连接期间复用；界面显示 PID，并可读取最近 12,000 字符 stderr 日志（按该进程配置的环境变量值脱敏）。禁用、删除、修改配置、空闲回收和正常后端关闭会关闭进程；先关闭 stdin，再由 SDK 按需升级至 SIGTERM／SIGKILL。异常退出后下次连接重新启动。测试已禁用的服务器也会启动一次连接，但不会把它加入对话。

可把 `docker` 配为程序、`["run", "--rm", "-i", "镜像名"]` 配为参数来连接预装的 stdio 容器，勿使用 `-t`。后端需自行具备 Docker CLI、daemon 访问权限和所需镜像；此次提供的是 stdio 子进程生命周期管理，依赖安装、镜像构建和脱离父进程的后台容器仍由部署方管理。

## 会话范围

普通问答在输入框的「+ → 技能与 MCP 范围」里配置，Bot 在「更多 → MCP 范围」里配置。

- **继承全局**：使用全局已启用的服务器，将来新增或启用的服务器也会加入。
- **勾选指定服务器**：只使用这些服务器与全局启用项的交集。
- **全部关闭**：该会话不提供 MCP 工具，包括随后新启用的服务器。

范围保存到会话，刷新、分支和切换会话保留各自设置。服务端在调用时核对身份、任务归属和范围；旧工具列表不能继续调用已经禁用的服务器或工具。启用服务器及其工具表示允许这些工具在选定会话使用，MCP 工具不按内置课程工具的 read/write 分类。

## 生命周期和失败行为

- 连接按账户、服务器和配置版本隔离；并发发现去重，空闲五分钟后释放，配置变更／禁用／删除会使旧连接失效。
- 单个服务不可用时，对话仍可使用内置工具，并展示 MCP 连接失败记录。
- 每轮直接注入最多 80 个 MCP 工具，元数据预算 60,000 字符。超限时改为每个服务器一个 gateway，模型先按名称／描述查询分页目录，再调用选中的工具；禁用工具和会话范围仍在调用时核验。后端发现目录上限为每服务 2,000 个工具、1,000,000 字符、100 页。
- 提供 Resources／Prompts 的服务也会出现 `@mcp/gateway`，支持 `resources`、`resource_templates`、`resource`、`prompts`、`prompt` 操作；该入口可像工具一样禁用。
- 工具结果超过 24,000 字符会截断并标记；Bot 还受其既有上下文预算限制。
- 超时、断线或取消后不自动重试业务调用；外部操作可能已生效，恢复时不重放结果未知的调用。Bot 调用写入既有 run_steps，沿用重启恢复机制。
- MCP 输出是外部服务返回的数据，不自动执行其中的 HTML、脚本或本地命令。

## 存储和部署

数据库迁移 13 添加 `mcp_servers` 和 Bot 会话范围字段。普通会话的 `mcpServerIds` 是同步记录中的非索引字段，无需 IndexedDB schema 升级。配置表按 owner 隔离，凭据沿用服务器 `credentials.key` 的 AES-256-GCM 加密能力。备份恢复时需同时保存数据库及配置密钥；公开接口、普通前端缓存和技能导出不含认证明文。

核心实现：`apps/api/src/mcp/`、`packages/contracts/src/mcp.ts`、`src/mcp/`。浏览器与 Bot 共用服务端连接管理及结果规范化。

## 技能依赖

技能 Markdown 的 frontmatter 可声明所需服务器的**显示名称**：

```markdown
---
name: 文献助手
description: 使用资料检索服务查找文献
requires-mcp: ["资料检索"]
---
先检索，再总结证据。
```

`requires-mcp` 使用单行 JSON 字符串数组；导入、编辑保存和序列化保留该字段。技能选择器与模型技能清单展示依赖；问答加载工具时，若当前技能范围内的依赖没有可用 MCP 工具，会在工具记录提示。依赖声明不会自动安装、授权或启用服务器，也不会扩大会话范围。

## 验证

- `npm run test:mcp`：真实 HTTP 协议连接、分页、认证、账号隔离、作用域、worker 鉴权、取消／超时、目录预算，以及 Bot 执行和重启不重放。
- 该命令也运行兼容性测试：JSON 预览校验／原子导入、真实 stdio 进程退出／日志脱敏、SSE 长连接与握手超时、资源／模板／提示词、OAuth PKCE／state 过期与重放／续期／撤销／实际回调路由，以及技能依赖序列化。
- `npm run build` 后 `npx tsx scripts/e2e-mcp.mjs`：桌面／手机配置、JSON 预览导入、stdio 表单／实际进程／日志脱敏、第二设备读取、草稿会话范围持久化；关闭用户页面后通过真实 Chromium worker 完成资料库、视频与阅读三类对话，并核验工具记录和技能缺失依赖提示。
- E2E 通过 `CHROMIUM_PATH` 指定浏览器；macOS 默认使用本机 Google Chrome。测试使用临时数据库、模拟模型及本地 MCP 服务，不消耗真实模型额度。
