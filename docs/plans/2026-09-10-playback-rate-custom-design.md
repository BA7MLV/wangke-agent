# 倍速档位（上限 4x + 自定义）设计

日期：2026-09-10
状态：已实现

## 背景与目标

控制栏顶栏左端的倍速快捷按钮（`src/components/RateButtons.tsx`）当前内置档位为 `1 / 1.5 / 2 / 3`，走 `remote.changePlaybackRate()`；倍率不做持久化（`MediaStorage.getPlaybackRate()` 返回 `null`）。

两个诉求：

1. 内置档位上限提到 **4x**。
2. 倍速**可自定义**——用户能录入任意倍率并作为常驻档位复用。

非目标：不改 Vidstack 自带倍率菜单的行为；不做「每个视频记各自倍速」（倍率仍不随视频持久化）。

## 方案

### 内置档位

`PRESET_RATES = [1, 1.5, 2, 3, 4]`。窄屏（`[data-sm]`）仍折叠为单个循环按钮，循环序列就是「内置档位 ∪ 自定义档位」排序后的数组。

### 自定义倍速

入口在「设置 → 播放 → 自定义倍速」（控制栏不再放配置面板：顶栏空间宝贵，且这是个一次性配置项）：

- `InputNumber`（`min=0.25`、`max=4`、`step=0.25`、支持手输）+「添加」按钮（回车同效，未输入时置灰）；
- 已添加的档位以 antd `Tag closable` 列出，点 `×` 删除；
- 归一化与去重：提交值归一到 **两位小数** 并夹到 `[0.25, 4]`；与内置档位或其他自定义档位重复时提示「已经在档位里了」，不重复入列。

档位一旦保存，播放器控制栏会把它们与内置档位合并平铺（`mergeRates` 去重升序），窄屏的循环按钮也按同一序列循环。

### 持久化

`settings.customRates: number[]`（zustand persist，默认 `[]`）。新增字段不需要 bump persist version——persist 默认做浅合并，旧存档缺该键时沿用默认值。同时补进迁移包的 `settings.json` 导出子集（导入侧是 `update()` 整体写回，无需白名单）。

## 校验边界

- 上限就是 `4`（`MAX_RATE`），下限 `0.25`（`MIN_RATE`）。
- 档位列表统一 `去重 + 升序`，避免自定义值与内置值打架造成按钮重复。

## 涉及文件

- `src/components/RateButtons.tsx`：档位集合（内置 ∪ 自定义）、循环逻辑
- `src/pages/Settings.tsx`：「播放 → 自定义倍速」卡片
- `src/utils/rate.ts`：档位纯逻辑（夹取 / 归一 / 去重 / 循环）
- `src/store/settings.ts`：`customRates` 字段
- `src/store/migration.ts`：迁移包导出子集
- `src/player-enhance.css`：档位按钮样式（多档时横向滚动）

## 变更记录

- 2026-09-10 首版：自定义入口做在控制栏的 Popover 上（宽屏「+ 自定义」、窄屏收成图标）。
- 2026-09-10 同日调整：**入口整体搬到「设置 → 播放」**，控制栏只保留档位按钮。理由：这是低频的配置项，弹层挤占顶栏；搬走后控制栏的「自定义」按钮与弹层样式（`.rate-btn-custom` / `.rate-custom-*`）一并删除。删除当前正使用的自定义档位时不再强制回落 1x —— 设置页与播放器可能不同屏，静默改播放速度反而意外；当前倍速不在档位里时循环按钮仍能正常取下一档。
