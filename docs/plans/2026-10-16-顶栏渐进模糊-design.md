# 顶栏渐进模糊：内容滚到栏下逐级虚化，昼夜两套自动成立

日期：2026-10-16
状态：**进行中**
范围：`ui/layout.tsx`（PageShell）/ `ui/layout.css` / `pages/course-chat.css`；六个页面共用，无页面级 JSX 改动。

## 背景与目标

用户要求：**各个页面的顶栏做渐进模糊，内容滚到顶栏下面时逐渐变糊**，且这套模糊要同时适配白天与黑夜。

现状：`.app-bar` 是主列里的一个普通流内兄弟节点，和滚动内容**不重叠**（`<header>` 占 60px，`<main>` 从它下面开始滚）。所以无论顶栏加多重的 `backdrop-filter`，它下面根本没有内容经过 —— 模糊永远是模糊一片同色画布。

因此这不是「给顶栏加一个 blur」，而是**先把顶栏从流内挪到滚动内容之上**，再给它铺一层逐级收窄的模糊垫层。

目标：

1. 顶栏浮在滚动内容之上（绝对定位），内容首屏仍从栏下方开始；
2. 内容一滚动就钻到栏背后，越靠上越糊，到栏底完全化开（无硬边）；
3. 课程库 / 学习 / 实时链路 / 对话页都成立；**播放页内容默认不穿越**（媒体页，视频顶部不该被虚化）；
4. 深浅两套主题都自然成立，不写死任何颜色。

## 一、结构：顶栏浮起 + 内容让位

主列（`ui/layout.tsx` 的 `.app-shell__main`）从 `flex col` 改成 `relative flex col`，`<header>` 从流内改成 `absolute inset-x-0 top-0 z-[5]`。这样 `<main>` 吃满整列高度，滚动时内容自然经过顶栏背后。

内容让位靠一个 CSS 变量 `--app-bar-h`：顶栏高度**不是常量**（含刘海安全区、副标题、右侧控件都可能撑高），所以用一个 `ResizeObserver` 量 `header.offsetHeight`，把它写进主列的 `--app-bar-h` 内联样式。首帧未量到之前用 `var(--app-bar-h, 60px)` 兜底。

- 普通页（课程库 / 学习 / 实时链路）：`.page-shell__content` 给内容列 `padding-top: calc(var(--app-bar-h) + 8px)`，与原 `pt-2` 视觉一致；
- 对话页（`fill`）：`.course-chat__messages` 的上内边距加一个 `--app-bar-h`；
- 播放页（`fill`）：`.player-layout` 整体下移一个 `--app-bar-h`，**不做穿越**。

## 二、渐进模糊垫层

顶栏里垫一层 `.page-app-bar__blur`（`absolute inset-0`、`z-index: -1`、`pointer-events: none`），里面 3 层 `<span>`，每层一条 `backdrop-filter: blur()`，半径由小到大、竖直 `mask-image` 覆盖带由满到窄：

```
L1 blur(1px)  mask 0% → 100%
L2 blur(2px)  mask 0% → 65%
L3 blur(4px)  mask 0% → 35%
```

叠起来就是「越靠上叠得越糊、到栏底每层都衰减到 0」的渐进曲线，所以栏底**没有硬边**。再叠一层 `::after` 淡色遮罩 `color-mix(in oklch, var(--background-secondary) …, transparent)` 保证标题可读，同样竖直衰减。

`z-index: -1` 是关键：顶栏自己 `z-[5]` 已经建了层叠上下文，模糊层落在顶栏内容的**下面**，不会把标题自己也糊掉；同时仍在 `<main>` 之上，能采到滚上来的内容当背景。

## 三、昼夜适配

颜色一律读 HeroUI 语义令牌：遮罩用 `--background-secondary`（页面画布色），浅色下是浅灰、深色下是深灰，标题用 `--foreground` —— 两套主题不需要任何分支代码。

不透明度靠 `color-mix` 给一个中间值，让背景色透上来一点点。另加两条兜底：

- `@supports not (backdrop-filter: blur(1px))`：关掉模糊层，遮罩改不透明；
- `@media (prefers-reduced-transparency: reduce)`：同上。

## 四、思考链吸顶的连带修正

对话页展开态思考链的标题是 `position: sticky`，靠 `--reasoning-sticky-gap = 28px` 钉在滚动容器**可见顶端**。消息区上内边距加了 `--app-bar-h` 之后，如果不动它，标题会钉到顶栏**背后**。

好消息是不用改组件：`top: calc(-1 * var(--reasoning-sticky-gap))` 是相对**内容盒顶边**算的，内容盒顶边跟着内边距一起下移了 `--app-bar-h`，所以钉住的位置也正好跟着下移到顶栏下沿 —— `--reasoning-sticky-gap` 保持 28px 不动即可。

有「课程上下文」条时（它固定在消息区上方），上下文条自己让出 `--app-bar-h`，消息区回到常规内边距（`:has(.course-chat__context)`），避免叠两次。

## 五、不做什么

- **不**给播放页做滚动穿越：视频是页面的主角，让它的顶部被虚化得不偿失。播放页顶栏照样是浮起的磨砂条，只是内容默认停在栏下。
- **不**改任何页面 JSX 与 `data-testid`：所有调整落在 PageShell 与页面 CSS，探针（`probe-app-shell-material` / `probe-rail-pages`）的几何断言不变。
