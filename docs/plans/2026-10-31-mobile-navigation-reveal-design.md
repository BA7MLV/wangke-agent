# 移动端导航：正文推开，露出侧栏

## Steps
- [x] 调整共享导航外壳和移动端动效，不改桌面侧栏与业务页面。
- [x] 验证导航开合、页面保活、无障碍、设置弹层与视口切换。

## 目标与边界

- 参照“正文推开露出导航”的交互思路自行实现，不引入 BoardUI 或复制 Pro 源码。
- 沿用 900px 断点与 HeroUI Drawer 的模态语义、焦点管理、Escape、点外部关闭和滚动锁。
- 正文保持原宽度和同一份 DOM，只平移并轻微缩小，同步变化圆角与遮罩；不动画布局宽高，不对整页做模糊。
- 侧栏宽度与正文位移共用一个令牌，窄屏至少留下 56px 正文供点击收起；避让安全区。
- 保留导航项、Recent、设置入口与已有跳转行为；设置打开或转为桌面时复位正文。
- 本次不增加滑动手势，禁用 Drawer 自带的独立拖动，避免导航与正文不同步。
- 支持减少动态效果；关闭后正文恢复 `transform: none`，不改变固定定位和全屏行为。

## 验证

- 独立浏览器上下文与本地存储，拦截云状态，不调用模型、不修改用户会话。
- 手机、窄手机、平板、横屏与桌面：开合后几何位置正确，无页面横向溢出。
- 背景不可交互，Tab 留在侧栏，Escape / 点击正文 / 关闭按钮均可收起并恢复焦点。
- 同一个聊天输入框、草稿、消息滚动位置在开合后保留；点击目的地后导航收起。
- 嵌套菜单不误关导航；设置弹层、断点变化、快速再次打开不留下遮罩或位移。
- 检查明暗主题、减少动态效果，以及现有侧栏回归测试；运行前端类型检查和生产构建。
