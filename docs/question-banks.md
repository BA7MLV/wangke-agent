# 原题题库：组合现有能力

## 设计边界

不新增数据库表、后端服务、任务类型、Agent 工具或独立题库页面。题库和讲义一样是普通 Markdown 资料，沿用文件保存、编辑冲突检查、资料目录、检索与备份路径。

- **理解与抽取**：内置「原题题库」技能规定逐页阅读、跨页拼接、答案核对、及时落盘和未完成范围；执行仍是现有 Agent 的 read/grep/edit。
- **唯一正文**：`/courses/{id}/questions.md` 只是同目录普通 Markdown 文件的稳定别名；不维护影子题目表。题目使用 `quiz` JSON 围栏，结构复用 `QuizQuestion`，用户笔记和覆盖说明在围栏外。
- **做题**：扩展现有 `present_quiz` 的 path/offset/limit 参数；宿主读取并校验文件最新版，每批至多五题。不是让模型再复制一遍答案。每轮只展示一批，避免覆盖尚未作答的题卡。批次位置随原有聊天题卡保存，刷新后仍可继续，不新增进度表。
- **批改**：沿用 `QuizCard` 的本地判分、计时和聊天作答持久化。题卡是历史快照；修改题库只影响新开的练习，不篡改旧成绩。
- **错题**：沿用 `/wrongbook.md` 和原 FSRS 逻辑，保留来源页码及图片引用，不另存作答表。
- **HTML**：题目可选 `presentation.html`，复用 `show_widget` 的校验、`WidgetBlock`、主题与不透明源沙箱。仅新增当前题目的草稿通道，学生仍需在可信宿主题卡中提交。不扩展网络权限、文件权限或通用工具接口，不接受 iframe 提供的判分/自评分。

## 原图和答案

`images` 只接受现有 `#source-image/...` 稳定引用，通过 `MaterialImage` 按需读取原文件、放大和回原文。`read /courses/{id}/images` 加 `crop="questions"`、`start/end`（一次1~3页）按 PDF 题号与文字坐标自动生成裁图引用。单/双栏编号题可自动定位，扫描件、无题号和不确定布局回退整页。可根据实际画面用 `regions=[{page,x,y,width,height}]` 修正，坐标为旋转后页面的千分比整数，不是像素。

区域引用格式为 `#source-image/{id}/page-{page}-region-{x}-{y}-{width}-{height}`，保存的是坐标，不另存图片数据库；展示时从原 PDF 渲染并裁取像素，刷新和错题仍能复现。不能越界或引用其他来源。自动分割不是视觉识别，无法保证所有复杂排版/跨页/共用材料的边界正确；相关页应一并保留，不凭空补齐。

题库每题必须有 `source` 和 `answerSource`：

- `original`：原卷或配套解析明确提供的答案。
- `verified`：用户明确核验的答案。
- `ai`：未核验的 AI 参考答案；可作答，不判对错、不计分、不进入错题本。
- `missing`：`answer=-1`；保留作答，不计分。

老聊天题卡不含新字段时仍按单选处理，原数字作答无需迁移。标准答案核验后修改题库，再新开练习。不能因题型不同而跳过原题。

## 题型与批改

`type` 支持 `single`（2~26项）、`multiple`（全对才对）、`boolean`、`fill`（每空精确匹配及核验别名）、`ordering`、`matching`、`freeform`、`composite`（独立小题，最多3层）。证明、计算、解答、作文、代码、作图等开放类型以 `freeform` 和原文 `typeLabel` 保留；通用文本输入可填写 Markdown，特殊交互可用 HTML。组合题保留共用材料与每个小题的来源/答案状态。详情与示例见内置「原题题库」技能。

客观题仅在 original/verified 时自动批改；不猜公式等价、不做未经指定的部分分。主观题展示已核验参考答案，学生明确自评后才以 `grading="self"` 写入原错题本，不进入自动成绩。可点击“请求 AI 参考批改”发送普通聊天，建议不会被当作确定判分。AI/缺答案题始终不判对错、不自动收错。

HTML 调用 `window.__wbw.setAnswerDraft(answer)`，宿主检查消息来源、题型、作答锁与长度，只更新草稿。`window.__wbw.answerInput`/`wbw:answerchange` 提供当前作答与提交状态，不提供标准答案、材料读取或数据库能力；标准输入可随时降级。自动判分、作答保存、错题均由宿主完成。

错题仍为同一 Markdown 文件。旧单选保留现有可编辑选项/表格格式；其他题型的选项结构、参考答案和作答记录使用受管理区域内的 JSON 围栏，保留主观自评标记，外部手写笔记不被覆盖。

## 使用

导入 PDF 到「资料」，打开资料的问答，点输入框「＋ → 提取原题为题库」。抽取结果写入同目录题库文件，并展示第一批题。以后可用「＋ → 开始做原题」，或打开生成题库资料的问答做题；说“继续”获取下一批。普通单选点选即批改，其他题型先填写再提交，答后显示解析，完成本批显示自动成绩及待核验/自评数量。

不会仅因上传资料就自动调用模型。长卷受现有 Agent 预算约束，按批保存并明确尚未覆盖范围，不新增后台全卷任务。扫描件 OCR 和主观题的确定性自动评分不在本次范围；扫描件可保留页面图，视觉定位后用区域裁图。
