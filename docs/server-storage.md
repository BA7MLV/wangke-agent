# 服务器存储统计

云端「设置 → 数据」显示服务器存储占用。进入时读取，点击「刷新」重新统计，并显示统计时间。

## 统计口径

- **应用数据大小**：`DATA_DIR`、`FILES_DIR`、`DB_PATH` 及其 SQLite `-wal` / `-shm` / `-journal`、`BOOTSTRAP_SECRET_FILE` 所在配置目录中的普通文件逻辑大小。独立配置在数据目录外的路径也计入。
- 分类为数据库与日志、上传文件与附件、资源与项目文件（`files/projects`）、系统与记忆文件（`files/system-files`）、其他持久化数据（包括配置、数据目录中的备份）。以服务器文件为准，不依赖数据库里的旧文件大小，不读取文件内容。
- 重叠目录和硬链接按设备号与 inode 去重；目录内符号链接、FIFO 等特殊文件不跟随。目录项自身的元数据不计入文件大小。
- **数据磁盘**：对实际数据路径使用 `statfs`；总容量为 `blocks × bsize`，已用为 `(blocks − bfree) × bsize`，可用为 `bavail × bsize`（非 root 可用空间）。同设备只显示一次，数据跨盘则分别显示。
- 文件逻辑大小与磁盘分配量可能因稀疏文件、文件系统压缩、元数据等不同。磁盘用量还包含其他应用；不把它当成本应用用量或用户配额。Docker 中显示挂载数据所在文件系统的容量，不代表云厂商配额。
- 应用总量不包含数据目录以外的备份、容器镜像、系统日志、临时目录或浏览器缓存。

## 接口与行为

`GET /api/v1/cloud/storage`：当前单用户服务器的账号认证接口；未登录返回 401，任务 Worker 返回 403。响应包含总大小、分类、磁盘、`partial` 和 `measuredAt`，不返回服务器路径、文件名或凭据。共享 DTO 位于 `packages/contracts/src/storage.ts`。

异步流式扫描，合并同时到达的请求；无持久缓存、无后台定时扫描。每次最多枚举 20 万项，扫描在操作之间检查 10 秒限额。权限／I/O 错误或触及上限时标记为不完整，界面显示「已统计的数据大小」，不能当作完整总量。磁盘容量读不到时单独标为不可用。扫描不是文件系统快照，写入／删除中的数字可能短暂变化。

页面初次读取失败显示重试提示，刷新失败保留并标明上次结果；不把请求错误显示为 0。支持中英文及手机布局。

## 验证

```sh
npm run test:storage
npm run test:storage:e2e
```

前者使用隔离目录测试真实文件、外置路径、SQLite 日志、去重、链接、不完整结果及认证；后者启动隔离 API + Web，验证真实统计、刷新、失败恢复及桌面／手机双语布局。截图位于 `test-results/server-storage/`。
