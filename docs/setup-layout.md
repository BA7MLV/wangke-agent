# 初始化页布局与字号

适用入口：`/#/setup` 和共用 `CloudGate` 的登录页。

## 布局与对齐

- 视口宽度 ≥ 960px：左侧 2.5D 画面、右侧表单，整体最大宽度 1200px。普通步骤的画面与表单垂直居中。
- 返回位于**右侧表单栏的左上角**，语言切换位于该栏右上角，步骤进度位于该栏底部右侧。返回与标题左边缘对齐，语言切换、表单右边缘与进度右边缘对齐。
- 左侧画面贯穿卡片内的完整高度，只保留 16px 外围留白；放大线稿，控制区不再占用左栏上下空间。
- 模型配置保留双栏，长表单随页面滚动，左侧画面在视口内保持可见。
- 窄屏使用上图下表单；手机端主要操作靠近底部。
- 标题、字段标签、输入框边缘、错误提示使用同一条左侧基准线。按钮文字统一居中。
- 配置页的供应商统一为图标在左、名称和说明在右的列表行。

## 提交反馈

- 填写期间图形保持静止，输入、删除、粘贴及指针悬停都不触发动画。
- 点击「创建管理员」或「登录」开始提交后才启动锁扣动画，提交结束后停止；欢迎页保留自动演示。
- 不监听输入事件，不读取或传递输入内容。减少动态效果开启时保持静止，离开步骤时销毁图形。

## 字号标杆

参考 Jira / Confluence 所属的 [Atlassian Design System — Typography](https://atlassian.design/foundations/typography)，查阅于 2026-10-29。

官方默认正文为 **14px / 20px**，小号正文 **12px / 16px**，大号正文 **16px / 24px**；标题阶梯为 **12、14、16、20、24、28、32px**。本页采用其中这些档位：

| 层级 | 字号 / 行高 | 用途 |
| --- | --- | --- |
| 辅助信息 | 12 / 16px | 供应商说明、状态 |
| 正文 | 14 / 20px | 标签、反馈、按钮 |
| 大号正文 | 16 / 24px | 输入内容、供应商名称 |
| 窄屏标题 | 24 / 28px | 页面标题 |
| 桌面标题 | 28 / 32px | 页面标题 |

`onboarding.css` 中以 `--ob-text-*` 和 `--ob-heading*` 统一定义，使用 `rem` 跟随应用的字号设置。沿用项目字体和深浅色主题，只参考标杆的字号与行高规则。
