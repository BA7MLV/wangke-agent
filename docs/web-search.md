# 联网搜索与网页读取

入口：**设置 → 联网搜索**（`#/settings/websearch`），需要连接本项目后端。搜索和网页读取默认关闭，可分别开启。设置按账号保存，设备间共用；API 密钥由服务器使用已有 AES-256-GCM 凭据能力加密，公开 API 不回传密钥。

支持 Tavily、Brave Search 和自托管 SearXNG。添加供应商、填写密钥或地址、启用供应商、选择默认项，再启用搜索并保存。SearXNG 需要开启 `search.formats: [html, json]`，地址由后端访问，允许管理员明确配置的内网服务。修改服务地址或供应商类型不会把旧密钥带到新目的地。

“测试搜索”使用已保存的设置执行真实搜索，会使用相应供应商额度。临时错误回退默认关闭；开启后按配置顺序尝试其他已启用供应商，仅网络故障、超时、429 和部分 5xx 触发回退，认证错误、空结果不切换。单次调用总期限 25 秒，每供应商 12 秒，每账号最多同时执行 4 个请求。

## 使用范围

- Bot、资料库助手、视频课程问答和阅读问答共用服务端工具；关闭或未配置的工具不会注入模型。
- `websearch` 接收 `query` 和可选的 `limit`（1–8），返回统一的标题、URL、摘要、可用的发布时间、实际供应商及耗时。去重并限制返回长度。
- `webfetch` 接收 `url`，读取公开 HTTP(S) 页面，抽取正文为纯文本；不执行 JavaScript、不使用登录状态。支持 HTML、文本、Markdown、JSON、XML；正文最多 16,000 字符并标记截断，响应体最多 1 MB。
- 运行时检查联网总开关，Bot 还检查项目网络策略；后台浏览器任务校验账号、任务和会话归属。设置变更/关闭会阻止旧工具继续调用。
- 网页抓取在连接时检查 DNS 地址、校验每次重定向，拒绝本机、内网、链路本地及非标准端口。自托管搜索地址仅来自用户保存的配置，模型不能传入供应商地址或密钥。
- 课程问答的来源存于工具记录，Bot 的来源存于专用消息；Web 界面可回看来源卡片。IM 渠道仍发送模型带引用链接的正文，不把来源 JSON 当作消息发送。

## 可插拔边界

这是编译期适配器机制，运行时可增删、启停和切换供应商。无需引入 OpenCode 或修改聊天协议；不加载任意远程插件代码。

`apps/api/src/web-search/providers.ts` 的 `SearchAdapter` 只负责构造供应商请求、提取供应商结果数组；服务层统一完成鉴权配置、超时、取消、回退、并发、规范化与长度限制。新增供应商需添加适配器、共享供应商类型、配置校验和设置页入口，补对应请求/响应测试。`WebSources` 只依赖统一的 `WebSearchResult`，无需随供应商增加而修改。

网页读取是独立工具，当前使用直接 HTTP 抓取、Readability 和不执行脚本的 DOM 解析。日后若增加托管抓取服务，可保留 `WebFetchResult` 契约替换执行层。搜索 MCP 仍可通过原 MCP 设置独立使用。

## 验证

`npx tsx scripts/test-web-search.mjs` 覆盖配置加密、账号隔离、冲突、供应商请求/结果、回退规则、取消、大小限制、URL/重定向保护、来源持久化及 Bot 工具循环。

构建后运行 `npx tsx scripts/e2e-web-search.mjs`，覆盖桌面/手机设置与卡片、密钥保存、关闭用户页面后的资料库/视频/阅读真实 Node 后台任务，以及路由身份、兼容浏览器任务范围、停用和冲突检查。测试使用模拟供应商，不消耗真实密钥额度。
