【题型与作答框架】
每类题型一个小节（h2），按"审题→找点→加工→书写"的顺序展开：
1. 归纳概括：问什么找什么，不引申。答案结构为"总括句+分条"，每条一个要点，要点词前置，后接材料依据。
2. 综合分析：先表态或释义（是什么），再从材料找依据分层论证（为什么），最后落到结论或对策（怎么办）。三层缺一不可时必须在讲义中点明。
3. 提出对策：三条来源——问题反推、原因反推、材料中的经验借鉴。对策写成"主体+手段+内容"，可执行；不写"提高认识、加强领导"这类空话，除非课程明确要求。
4. 贯彻执行（应用文）：先定文种，再按文种决定格式要素，格式规则照录课程所讲，不自造。
5. 申发论述（大作文）：按标题、开头、分论点、结尾四部分整理，见下。

【答案书写规范】
1. 分条作答用 list：每条以要点词开头，后接一句材料依据；条数与分值匹配（10 分约 4-5 条），课程有明确要求时以课程为准。
2. 题目字数限制必须注明：如"不超过 200 字"，写在小节第一段。
3. 材料长段不抄录，只保留得分关键词与逻辑关系；需要完整示范答案时，示范答案独占若干 para，前面一句说明"以下为示范作答"。

【应用文格式速查】
1. 完整格式四要素：标题、称谓、正文（背景—事项—要求/号召）、落款（发文单位+成文日期）。
2. 取舍规则按文种写清：讲话稿有称谓无落款，通知有落款，倡议书四要素齐全；课程没讲的文种不补。
3. 正文部分的常用句式（如倡议书的结尾号召）用 list 逐条给，不写成大段范文。

【大作文结构】
1. 标题：观点式，直接亮明总论点；不用疑问句，不文艺化。
2. 开头：三句话以内——背景引入、问题或意义分析、亮明总论点。
3. 分论点：广东申论偏重策论，分论点优先对策型（"以……为抓手，推进……"）。每个分论点一个小节（h2），内部按"论点句→阐释→材料或政策例证→小结句"展开；例证优先用课程给的材料，不虚构数据与案例。
4. 结尾：回扣总论点，可升华到政策高度，一两句话收住，不空喊口号。

【广东考情】
1. 分级分类：县级卷侧重宏观治理与发展，乡镇卷侧重基层实务；课程有区分时，在相关题型小节注明适用卷别。
2. 本土话题素材按主题整理成 list，每条写清"素材+可用主题"：粤港澳大湾区建设、制造业当家、百县千镇万村高质量发展工程、绿美广东生态建设、数字政府改革等；素材以课程所讲为准，不写成新闻摘抄。
3. 涉及真题标注年份与卷别：如"2024 年广东省考乡镇卷"；来源不明则不标注。
