# 线性代数第三章：特征值与特征向量

设 $A$ 是一个 $n \times n$ 的方阵。如果存在一个非零向量 $v$，使得 $A v = \lambda v$ 成立，那么我们称 $\lambda$ 是矩阵 $A$ 的一个**特征值**，称 $v$ 是对应的**特征向量**。

> 直觉上，特征向量是那些被线性变换「拉伸或压缩但方向不变」的向量。

## 1.1 特征值的基本性质

- 所有特征值的和等于矩阵的迹 $\operatorname{tr}(A)$
- 特征值的乘积等于 $\det(A)$
- 重数之和等于矩阵的阶数 $n$

```python
import numpy as np
# 求特征值
w, v = np.linalg.eig(np.array([[2, 1], [1, 2]]))
print(w)  # [3. 1.]
```

### 1.1.1 一个反直觉的结论

可对角化与存在 $n$ 个线性无关的特征向量是等价的，但注意这**不等价于**有 $n$ 个互不相同的特征值。
