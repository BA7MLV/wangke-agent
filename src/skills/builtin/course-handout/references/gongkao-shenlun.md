# 公考申论讲义专题

面向公务员、事业单位相关申论课程，整理题型、材料加工与作答方法；不是对所有文种强套公文版式。来源、文件保存及通用写作沿用主技能与 writing.md。

## 五类题型

每类题型按审题 → 找点 → 加工 → 书写组织，分清题目要求、课程方法与补充解释，只展开已读课程涉及的题型。

1. 归纳概括：问什么找什么，不无据引申。整理“总括句＋分条”时，每条保留要点词及材料依据；合并同类项时不抹掉不同主体、对象或层次。
2. 综合分析：围绕是什么（表态或释义）、为什么（材料依据与分层论证）、怎么办（结论或对策）说明作答逻辑；具体题目需要哪几层以题干和课程为准，不强行为每题补齐三段。
3. 提出对策：区分问题反推、原因反推、材料经验借鉴三类来源。写清主体、手段与内容，确保可执行；“提高认识、加强领导”不能脱离材料单独当万能答案，课程明确要求时保留并说明语境。
4. 贯彻执行（应用文）：先审任务、身份、对象、目的与文种，再确定内容和格式要素；照录课程与题目要求，不自行创造文种规则。
5. 申发论述（大作文）：按标题、开头、分论点、结尾整理立意、结构与论证，明确如何从给定材料或题意得出总论点和分论点，不只有空模板。

## 答案加工与示范

- 题目字数限制、对象、任务和特殊要求在对应小节显著注明，例如“不超过 200 字”。分条用 Markdown 列表，要点词前置，后接必要依据。
- 条数服从材料要点、题目要求和课程评分说明，不把“10 分约 4–5 条”当作评分定律，不虚构分值分配或删点凑数。
- 长材料可概括，但保留得分关键词、主体、因果、对照与限定条件。关键词串联不等于完成分析，需要解释归类与加工依据。
- 完整示范答案单列，注明“以下为示范作答”，保留正常段落或列表，不受旧 para 块或表格字数约束。区分原文范答、用户核验与 AI 补充；示范字数应核对，不能声称未经证据支持的官方标准答案。

## 应用文格式

- 标题、称谓、正文、落款是检查维度，不代表每种文种都必须齐全。正文可按背景、事项、要求或号召展开，依据任务取舍。
- 课程若讲“讲话稿有称谓无落款、通知有落款、倡议书四要素”等规则，连同适用题目、文种和简化条件整理；不可忽略“只写正文、不考虑格式”等题目指令，也不把课堂速记变成无条件法规。
- 常用句式按功能与使用条件列出，不能用大段套话替代材料信息。课程未讲的文种不擅补成课程原话；用户明确要求拓展时标明补充。
- 这里的格式是考试答案内容要素，不是字体、字号、页边距或 Word 自动编号；不输出旧公文 IR。

## 大作文

- 标题明确总论点，默认观点式，不以疑问或修辞掩盖立意；课程和题目有其他要求时遵从，不把风格偏好当成唯一正确形式。
- 开头简洁连接背景、问题或意义与总论点，可参考三句话以内，不因句数限制删去必要逻辑。
- 每个分论点可单独成节，保留论点句 → 阐释 → 材料或政策例证 → 小结的论证链；篇幅与层级按实际内容调整，不强凑四句。
- 广东策论相关课程可优先整理对策型分论点，如“以……为抓手，推进……”，但须以该课程、题目与卷别为依据，不能把所有广东作文都预设为策论文。
- 例证优先用课程给出的材料；不虚构政策出处、案例或数据。结尾回扣总论点，可联系有依据的政策背景，避免空喊口号。

## 广东上下文与真题出处

- 保留课程对县级卷、乡镇卷的区分：宏观治理与发展、基层实务等侧重应标注适用卷别及课程背景，不断言所有年份考情相同。
- 本土素材按“素材＋可用主题”组织，可能涉及粤港澳大湾区建设、制造业当家、百县千镇万村高质量发展工程、绿美广东生态建设、数字政府改革等；只写来源实际涉及的内容，不把主题清单扩写成无来源新闻汇编。
- 真题标明有证据的年份和卷别，例如“2024 年广东省考乡镇卷”；未说明则不编造。课程提供的政策与考情保留时点，未经核验不说是当前最新。
- 需要忠实提取整套材料、原题、标准答案并练习时使用原题题库流程；主观作答不能仅凭文本相似度宣布自动判分。
