# 公考行测讲义专题

面向公务员、事业单位相关行测课程，整理原课知识、题型与解题方法，不替代原题题库提取或正式判分。通用写作、证据和保存规则沿用主技能及 writing.md。

## 五模块与广东题型

1. 言语理解与表达：选词填空（语境分析、词语辨析）、片段阅读（主旨概括、意图判断、细节理解）、语句表达（排序、衔接）。
2. 判断推理：图形推理（位置、样式、数量、空间重构）、定义判断、类比推理、逻辑判断（翻译推理、加强削弱、真假话）。广东相关课程还涉及科学推理，以物理为主，兼及化学、生物、地理常识；适用年份、地区与卷别以课程实际内容为准。
3. 数量关系：数学运算（行程、工程、利润、排列组合、概率、几何、容斥）；广东课程涉及的数字推理保留等差、等比、和数列、幂次、分式数列等识别方法，不把特定地区考情推广到所有考试。
4. 资料分析：增长、比重、平均数、倍数四类核心考点，分别保留概念、列式、速算与易混点。
5. 常识判断：政治、法律、经济、历史、科技、地理，按知识点和必要辨析整理，不凑长篇论述；时效性结论保留课程所述背景，不自动冒充当前最新政策。

只展开来源实际覆盖的模块；这份清单用于识别内容，不是给每门课补齐全部模块的命令。

## 题型小节结构

一个题型一个 Markdown 小节，按识别特征 → 解题步骤 → 有条件的技巧 → 例题与易错点展开；来源缺项可省，不编造。

- 识别特征说明题干、问法与适用边界，避免只抄题型名称。
- 解题步骤用有序列表，每步一个明确动作，通常从审题、定位开始，到核对答案或选项结束；可参考 2–5 步，但复杂论证不为步数限制删关键环节。
- 口诀、排除规则、速判技巧逐条交代适用条件、失效场景；不写“看到就选、秒杀一切”等无条件断言。
- 例题保留必要条件、数据、问法及辨析所需选项；长材料可概括，但不能删去决定答案的限定词或逻辑关系。解析指出用了哪一步、哪条规则，并保留必要列式、计算或逻辑推导，不只给字母让学生回视频补过程。
- 一个考点的相遇、追及等变形尽量合并对比，不反复铺垫定义；易错点说明错因，而不只是“注意审题”。

## 数量、资料与科学推理

- 公式先说明量的含义、单位和使用条件，再列式，例如“基期量=现期量/(1+增长率)”。简单式可用清楚的纯文本，复杂式可用 Markdown LaTeX，不沿用旧 IR 或强制纯文本限制。
- 速算写清适用选项差距、截位方法、允许误差与偏差方向；无法保证误差方向时说明取决于哪些量，不把课程中的条件性技巧绝对化。
- 首次涉及同比与环比、百分点与百分数、平均数增长率与两期比重差时给出辨析，说明分母与比较对象。
- 科学推理保留物理等学科的前提、方向、单位和边界，图形推理不凭无法确认的原图细节猜规律。确需展开公式课程写法时，再按需读取 math-writing.md，不加载无关专题。

## 出处与边界

- 课程说“加强型”不擅改“支持型”，题型简称沿用来源。
- 真题出处按课程证据写年份、地区、卷别，如“2024 年广东省考县级卷”；来源未给则注明未说明，不杜撰。
- 讲义例题可以围绕方法适当压缩；用户要逐题原题、选项、原图、答案出处及练习时，改用原题题库流程，不把压缩例题当作完整题库。
