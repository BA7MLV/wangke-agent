# 数学与公式类课程

适用于数学、物理等公式较多的 Markdown 讲义；通用写作与来源、保存规则沿用主技能及 writing.md。

## 定义、定理与符号

- 定义准确说明对象、条件与含义；定理给出完整假设和结论，再说明适用场景。不得把充分条件改成充要条件、把特例推广为一般规律。
- 符号沿用原文，首次出现解释含义、取值范围及必要单位；不随意把原文术语换成自造符号，或把有区别的符号混用。物理公式保留单位、方向、正负号、近似条件与边界条件。
- 定理、公式与使用时机相连，区分精确等式、近似估计和经验规则。课程未给证明时可说明未展开；补充证明必须明确标为补充。

## 公式表达

- 简单式可直接写 `f(x)=x²`、`aₙ`、`√(a+b)`、`(a+b)/(c+d)`；括号明确分母、指数、积分区间与运算顺序，不因转成纯文本改变含义。
- 当前共享 Markdown 预览支持 LaTeX：行内用 `$f'(x)$` 或 `\(f'(x)\)`，独立公式用成对的 `$$` 或 `\[`、`\]`。例如 `$\frac{a+b}{c+d}$`。不要把待渲染公式放进代码围栏，不输出无定界符的 LaTeX 命令。
- 复杂公式单独成段，前后说明变量、含义与用途；希腊字母可用 α、β、Δ、Σ、π 等字符或相应公式命令。渲染不支持的写法改成等义的受支持写法或带清楚括号的纯文本，不强禁 LaTeX，也不声称所有外部导出工具都支持。
- 例：拉格朗日中值定理需同时写明在 [a,b] 连续、在 (a,b) 可导，以及存在 ξ∈(a,b) 满足 f(b)−f(a)=f'(ξ)(b−a)，不能只写“可用中值定理估计”。

## 例题与推导

按题目条件与所求 → 方法选择及依据 → 有序解题步骤与必要演算 → 结论及检验 → 易错点组织，不套用 IR 块。

- 保留定义域、关键变形、分类讨论、解的舍取和检验；不能只留思路骨架或让学生回视频补齐关键步骤。用户只要速记时可压缩机械重复计算，但交代省略范围。
- 图像或几何证据需要真实原图，图上无法确认的条件不猜。辅助生成图明确是示意图，不替代证明；静态/交互图按主技能的会话与保存边界处理。
- 解释常见错误的原因与适用边界，如除以可能为零的量、开方后的符号、积分换元的区间、物理量单位；原文未给出的演算标明是补充，不冒充课程推导。
