description: 公务员、事业单位考试行政职业能力测验（行测）课程的讲义写作规范：言语理解、判断推理、数量关系、资料分析、常识判断各模块的题型结构、解题步骤与例题写法，含科学推理、数字推理等广东特色题型。

【模块与题型速览】
1. 言语理解与表达：选词填空（语境分析、词语辨析）、片段阅读（主旨概括、意图判断、细节理解）、语句表达（排序、衔接）。
2. 判断推理：图形推理（位置、样式、数量、空间重构）、定义判断、类比推理、逻辑判断（翻译推理、加强削弱、真假话）；广东另考科学推理（以物理为主，兼及化学、生物、地理常识）。
3. 数量关系：数字推理（广东保留题型：等差、等比、和数列、幂次、分式数列）、数学运算（行程、工程、利润、排列组合、概率、几何、容斥）。
4. 资料分析：增长、比重、平均数、倍数四类核心考点的列式与速算。
5. 常识判断：政治、法律、经济、历史、科技、地理，按知识点逐条整理，不展开论述。

【小节结构：一个题型一个小节】
小节（h2）内按固定顺序展开，缺项可省但顺序不乱：
1. 识别特征：什么题干、什么问法属于本题型，一两句话说清，写进 para。
2. 解题步骤：用 ordered list，每步一个动作，2-5 步；第一步通常是审题或定位，最后一步是核对选项。
3. 要点与技巧：用无序 list；口诀、排除规则、速判技巧逐条写，每条必须写清适用条件，不写"看到就选""秒杀一切"这类无条件断言。
4. 例题：para 写题干要点（长材料只保留条件、数据与问法，不全文抄录）→ 解析（写明依据哪一步或哪条技巧得出答案）→ 易错点用 note（无则省略）。

【公式与速算（数量、资料专用）】
1. 公式纯文本排版：上标用 ² ³，分数写 a/b，根号写 √，百分号直接写 %；不写 LaTeX 命令。
2. 公式先给含义再列式：如"基期量=现期量/(1+增长率)"，独占一个 para，随后一句说明使用时机。
3. 速算技巧写明适用场景与误差方向：如"选项首位不同可截位直除，截前两位，结果偏大"。
4. 易混概念第一次出现时给一句话辨析：同比与环比、百分点与百分数、平均数增长率与两期比重差。

【表述要求】
1. 术语与课程原文一致：课程说"加强型"就不改写"支持型"，课程说"图推"就沿用。
2. 例题答案只给选项字母与关键依据，不复述完整推导流水账；需要完整过程时提示学生回视频对应讲解。
3. 涉及真题标注来源：年份+地区+卷别，如"2024 年广东省考县级卷"；课程未说明来源则不标注、不杜撰。
4. 一个考点的多个变形（如行程问题的相遇、追及）合并为一个小节，用 list 分条对比，不拆成多个小节重复铺垫。
