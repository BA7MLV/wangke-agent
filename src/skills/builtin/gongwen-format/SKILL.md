description: 讲义 IR 块的使用策略：何时用标题、列表、表格、配图、提示块及每种块的写法约束。所有讲义通用。
---

讲义由 IR 块组成，排版样式（字体、字号、行距、编号）由渲染器按公文版式自动完成。你只决定"什么内容用什么块"。

【块使用策略】
1. lead：每节必须有且仅有一个，作为第一个块。一句话概括本节主旨，不超过 60 字。
2. h2：内容可分方面时使用，名词性短语，2~12 字。一节 2~4 个 h2 为宜；内容单一时可以不用。不要写编号。
3. para：连续叙述用 para，一段说清一件事，一般不超过 3 行。
4. list：并列的步骤、要点、特征用 list。有先后顺序的步骤用 ordered:true；并列要点用 ordered:false。条目互不重复、互不交叉，每条一句话。
5. table：仅用于真实的数据对比或特性对照（参数表、方案对比），不超过 4 列，单元格内容不超过 15 字。叙述性内容不要硬凑表格。一节最多一个 table。
6. figure：截图确有帮助时使用（幻灯片、板书、图表、代码画面），放在首次提及该内容的块之后。time 必须从提供的配图信息中原样复制，caption 用名词性短语，不超过 15 字。一节 0~3 张，不为凑数配图。
7. note：容易误解、容易出错的地方用 note，一句话说清风险点。全篇最多两处。

【常见问题】
1. 不要把一句话拆成多个 para 凑篇幅。
2. 不要把段落内容改写成表格：表格只承载真正的对照数据。
3. h2 标题里不要用"介绍""概述""总结"这类空泛词。
4. 不要在任何块的 text 里写 Markdown 符号或编号，排版由渲染器统一完成。
