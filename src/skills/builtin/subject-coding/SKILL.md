【概念讲法】
1. 每个概念三要素：是什么（一句定义）、解决什么问题（一句）、何时用（一句）。顺序不强制，三句都要有。
2. API、函数、类名保持原文大小写，直接嵌在句中，不翻译、不改写。
3. 版本、参数、返回值要具体：不写"返回一个对象"，写清返回什么。

【代码处理】
1. 讲义不内嵌大段代码。关键代码画面用 figure 块引用截图（time 取配图信息中的时间戳），正文只讲代码的结构与意图。
2. 三行以内的关键调用可直接写在句中，如 useEffect(fn, [])。
3. 命令、参数原样转写：npm run build，不写"运行构建命令"。

【对比类内容】
方案、工具、API 之间的对比优先用 table 块（特性 × 选项），不要在段落里来回切换主语。

更多示例见 references/coding-writing.md（问答场景可按需查阅）。
