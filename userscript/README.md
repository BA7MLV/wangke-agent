# B 站导入 · 油猴桥

> ⚠️ 仅供个人学习使用。请遵守哔哩哔哩用户协议，勿用于批量抓取或下载付费 / 会员内容。详见项目根目录 README 的「免责声明」一节。

Cloudflare Worker 的出口 IP 常被 B 站拒绝。这支脚本挂在**网课学习助手页面**上，用 `GM_xmlhttpRequest` 从**本机 IP**直连 B 站 API / CDN，并带上 `Referer: https://www.bilibili.com`。

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox / Safari 桌面端）
2. 打开网课助手 → **设置 → 哔哩哔哩导入**，点「安装油猴脚本」；或把 `wangke-bili-bridge.user.js` 拖进 Tampermonkey
3. 刷新网课助手。设置页应显示「油猴桥已连接」
4. 库页粘贴 BV / 链接即可导入。可选：在设置里贴自己的 `SESSDATA` 以带上登录态（清晰度由 B 站按你的账号权限决定）

## 脚本升级（重要）

浏览器里装的副本**不会**自动更新（本地文件没有 `@updateURL`）：脚本改版后要回**设置 → 哔哩哔哩导入 → 安装脚本**重新装一次，装完刷新助手页面。设置页那行会显示当前桥的版本（例如「已连接 v2.1.1」），对不上就是没生效。

## 设置页那张卡片长什么样

- **装了桥**：只有一行结论（`已连接 v2.1.1 · 已登录：<昵称>`）+ 安装/重装按钮；代理地址与 Cookie 收进「备用出口」，默认折叠 —— 用不上就别占地方。
- **没装桥**：「备用出口」自动展开（这时它才是主路径），填代理地址即可用。

## 「读取本机 Cookie」读不到？

设置页会写明是哪一种（不再是一句笼统的「没读到」）：

| 提示 | 原因 | 怎么办 |
|---|---|---|
| 没检测到油猴桥 | 脚本没装 / 没注入（页面需带 `data-wangke="1"`） | 点「安装脚本」后刷新助手页 |
| 当前脚本是 x.y.z 版，没有读 Cookie 的能力 | 装的是 2.0 及更早（没有 `GM_cookie`） | 重新安装脚本 |
| 脚本读不到 Cookie（不支持或未授权 GM_cookie） | Safari 的 Userscripts 等不实现 `GM_cookie`；或扩展拒了这次调用 | 手动粘贴，或**直接留空**（装了桥时请求会自动带上浏览器自己的 Cookie） |
| 能读 Cookie，但本机没有 bilibili.com 的 | 没登录 B 站 / 无痕窗口 / 容器标签页隔离 | 在浏览器登录 B 站后重试 |
| 读到 0 项 Cookie，但桥出口已登录 | 扩展没提供 `GM_cookie` 明细（真登录态仍在） | **什么都不用做**：桥的请求自带浏览器 Cookie，输入框留空即可 |

> 怎么判断自己是不是「登录了」：看设置页那行「已登录：<昵称>」—— 那是桥用浏览器自己的 Cookie 调 `nav` 问出来的，比 Cookie 明细更可信。

> 留空不影响导入：油猴桥的 `GM_xmlhttpRequest` 在本机发起，浏览器会自己带上 bilibili.com 的 Cookie。填写主要是为了**代理回退路径**（`X-Bili-Cookie`）与状态可见。

## 限制

- **iPad / 手机 Safari PWA 用不了油猴**，请改用本机文件导入，或在电脑浏览器里导
- Tampermonkey 无法真正流式下载，整段 m4s 会先进内存再封装，超大视频可能顶内存
- 脚本用 `@match *://*/*`，但只有页面带 `data-wangke="1"` 才会注入（助手的 `index.html` 已加）
